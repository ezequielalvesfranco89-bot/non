Vamos testar o TikTok Live Battle 2.0

O primeiro teste é no seu computador, usando espectadores de mentira. Não precisa abrir uma live, fazer login no TikTok, pagar presentes ou instalar OBS.

Use um computador com Windows 10 ou 11. Estes arquivos não são um aplicativo para celular. Este pacote contém scripts de início, não um EXE pronto.

1. Baixe e extraia o ZIP

  1. Na página do projeto no GitHub, confira a branch tiktok-live-battle-2.
  2. Clique em Code e depois Download ZIP.
  3. Abra a pasta Downloads. Clique com o botão direito no ZIP e escolha Extrair Tudo. Clique em Extrair.
  4. Abra a pasta extraída. Entre em tiktok-live-battle.

Você deve ver os arquivos TESTAR-PRIMEIRO.bat, iniciar.bat e este tutorial. Não execute o jogo de dentro da janela do ZIP.

2. Prepare o Python — só na primeira vez

  1. Se você já tem Python 3.11 ou mais recente funcionando, avance para o passo 3.
  2. Se não tem, abra o site oficial do Python para Windows. Recomendamos Python 3.12, instalador de 64 bits para um computador Windows comum.
  3. Abra o instalador. Marque Add python.exe to PATH e escolha Install Now.
  4. Espere aparecer que a instalação terminou. Feche o instalador.

O Python permite rodar o jogo local. Não é necessário instalar Node.js para usar esta versão já compilada.

3. Abra o primeiro teste

  1. Dê dois cliques em TESTAR-PRIMEIRO.bat. A janela pode mostrar o nome sem “.bat” se o Windows esconder as extensões.
  2. Uma janela com mensagens (terminal) vai abrir. Na primeira vez ela instala as bibliotecas: aguarde, sem fechar. Essa etapa precisa de internet.
  3. Depois o programa inicia e abre o navegador. A janela do terminal mostra o endereço correto, normalmente http://127.0.0.1:8766.
  4. Se o navegador não abrir sozinho, copie o endereço mostrado no terminal e cole na barra de endereços do Chrome ou Edge.

Você deve ver “LIVE BATTLE 2.0”, “Sistema online” e “Modo teste”. Deixe o terminal aberto; fechá-lo encerra o servidor.

4. Confira se o jogo funciona

  1. Na aba Visão geral, clique em Iniciar batalha. Você deve ver o monstro e a barra de vida.
  2. Desça até Laboratório de interações. Clique em Rosa. A vida do monstro deve diminuir e o dano aparecer.
  3. Clique em + Novo seguidor. O nome aparece nas boas-vindas e o contador aumenta. Clique de novo com o mesmo ID: o contador não aumenta, porque essa pessoa já contou.
  4. Use + Seguidor com novo ID para testar pessoas diferentes. Ao chegar à meta, deve aparecer uma recompensa coletiva.
  5. Clique em 100 curtidas: o jogo carrega um golpe coletivo e libera uma carga de !poder.
  6. Use os botões !atacar, !curar, !defender e !poder. Espere pelo menos 3 segundos entre comandos do mesmo espectador.
  7. !curar recupera a vida da equipe, não a do monstro; se a equipe já está com 100, não há vida extra para recuperar. !defender reduz os ataques do chefe por alguns segundos. !poder só funciona com carga disponível.
  8. Experimente Leão lendário para terminar a batalha mais rapidamente. Ao derrotar o chefe, uma fase nova começa após a celebração.

Funcionou sem TikTok? Ótimo: o teste local está concluído. Tudo o que você gerou até aqui é SIMULADO.

5. Veja a tela da transmissão

  1. Clique em Configurações.
  2. Abra o link de overlay vertical. Uma nova aba mostra somente o jogo, sem o painel administrativo.
  3. Você pode usar essa tela no OBS depois. Não precisa configurar OBS para confirmar que o jogo funciona.

6. Na próxima vez

Dê dois cliques em iniciar.bat. Não é necessário reinstalar tudo a cada abertura. Para parar, volte à janela do terminal e pressione Ctrl+C.

Se não abriu

  • Python não encontrado: refaça o passo 2; marque a opção PATH. Abra o arquivo de teste de novo.
  • Arquivos incompletos: use “Extrair Tudo” e confira se você está na pasta tiktok-live-battle, não dentro do ZIP.
  • Instalação falhou: abra a pasta .logs e depois instalacao.log. Copie a mensagem de erro para pedir ajuda.
  • O navegador não abriu: mantenha o terminal aberto e use o endereço que ele mostra. O programa tenta outra porta se a anterior estiver ocupada.
  • Aparece servidor desconectado: veja se o terminal foi fechado ou se ele mostra algum erro.
  • Sem monstro: use um Chrome ou Edge atualizado com WebGL habilitado; informe o erro do navegador se persistir.
  • Sem som: clique em “Ativar som” e confira o volume nas configurações.
  • O Windows bloqueou o arquivo: leia a mensagem e confirme a origem do download. Não desative antivírus ou verificações de segurança. Copie a mensagem para pedir ajuda.

Erros ao abrir também são registrados em %LOCALAPPDATA%\TikTokLiveBattle2\inicializacao.log. Não envie senhas, cookies ou chaves de acesso.

TikTok LIVE — só depois do teste local

Quando o jogo local já estiver funcionando, execute instalar-live.bat, feche o programa e abra de novo. Depois selecione LIVE e informe o @ de uma transmissão pública ativa. O programa não pede senha.

A entrega de eventos reais depende do TikTok e da integração. A presença de FollowEvent foi verificada, mas uma transmissão real não foi validada aqui. Este tutorial de Windows também precisa ser conferido no seu computador: os testes desta entrega foram executados em Linux.
