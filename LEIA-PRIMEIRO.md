# Baixar e iniciar o TikTok Live Battle

1. Nesta branch `tiktok-live-battle`, clique em **Code** e depois **Download ZIP**.
2. Extraia o ZIP no computador.
3. Abra a pasta extraída e entre em **tiktok-live-battle**.
4. Instale Python 3.11 ou superior (recomendado: Python 3.12), incluindo o Python Launcher.
5. Execute **instalar.bat** e aguarde a instalação terminar.
6. Execute **iniciar.bat**. O navegador abrirá o programa localmente.

O programa começa no modo de teste. Clique em **Iniciar batalha** e experimente os presentes e seguidores simulados.

A interface compilada já está incluída: não é necessário instalar Node para usar o pacote. O sistema precisa instalar as dependências Python na primeira execução.

Esta entrega contém código-fonte e scripts; não inclui um EXE pronto. A conexão com uma transmissão real e a instalação nativa no Windows ainda precisam de validação. Consulte as instruções completas em [tiktok-live-battle/README.md](tiktok-live-battle/README.md).
