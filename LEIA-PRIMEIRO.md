# Live Studio — comece aqui

Este é o novo estúdio de interações com 60 ações, presentes e seguidores simulados, física 2D e editor visual de regras.

## Testar sem instalar nada

1. Clique em **Code → Download ZIP** e espere terminar.
2. Clique com o botão direito no ZIP → **Extrair tudo → Extrair**.
3. Abra a pasta extraída e entre em **live-studio**.
4. Abra **TESTAR.html** no Chrome ou Edge.
5. Clique **Ativar sons** e **Enviar presente de teste**. A Rosa cria uma flor na ilha.

O tutorial completo está em **live-studio/TUTORIAL.html**. Ele explica seguidores, metas, editor, minigames, exportação das regras e OBS. Não precisa instalar Python ou conectar uma conta para testar.

**TikTok, YouTube e Twitch ainda não estão conectados.** Todos os eventos desta primeira experiência são simulados; os limites e permissões estão explicados no painel.

Veja [as instruções completas](live-studio/README.md) e [a validação](live-studio/docs/VALIDACAO.md). Para OBS, existe servidor Node opcional com overlay sincronizado.

A pasta tiktok-live-battle é de uma versão anterior; para esta experiência, entre em **live-studio**.
