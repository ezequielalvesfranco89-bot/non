# TikTok Live Battle 2.0 — primeiro teste

1. Clique em **Code → Download ZIP** nesta branch `tiktok-live-battle-2`.
2. No Windows, clique com o botão direito no ZIP e use **Extrair Tudo**.
3. Abra a pasta extraída e entre em **tiktok-live-battle**.
4. Abra **TUTORIAL_TESTE.html**: ele explica cada clique e o resultado esperado.
5. Instale Python 3.11+ (recomendado 3.12), se ainda não tiver.
6. Dê dois cliques em **TESTAR-PRIMEIRO.bat** e aguarde.

Não rode os arquivos dentro do ZIP. Não precisa instalar TikTok, OBS ou Node para o primeiro teste. Os scripts mantêm os erros na tela e salvam diagnóstico.

O teste inicial não conecta a uma live real. O pacote contém código e scripts, não um EXE pronto. A instalação Windows precisa ser validada no seu computador; os testes do desenvolvimento foram executados em Linux.
